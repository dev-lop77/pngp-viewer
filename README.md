# PNGP Viewer

A navigable 3D web viewer for the Gran Paradiso National Park, inspired by
[ode-to-yosemite](https://github.com/shlokkhemani/ode-to-yosemite).

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the plan and
[docs/PROGRESS.md](docs/PROGRESS.md) for current status — read the latter
first when picking this project back up.
